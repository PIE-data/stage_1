# English stop words — Stage 1 inverted index
#
# Committed deliberately rather than taken from a library: NLTK, spaCy, Lucene
# and every JS/Go package ship different lists, so three implementations using
# "the standard list" would index different vocabularies and the canonical
# hashes would never match.
#
# Format (SPEC.md §3.3): one lowercase term per line, UTF-8, LF endings.
# Lines starting with # and blank lines are ignored.
#
# Scope: closed-class function words only. Contractions appear in their
# post-tokenizer form, since the tokenizer keeps an apostrophe between word
# characters. Numerals ("one", "two") are deliberately absent: they can be
# topical. So are "time", "man", "way" — those are content words.
#
# Changing this file changes every index. It is frozen with the spec: a change
# requires a spec-change PR and regeneration of spec/golden/expected.sha256.
